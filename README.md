# SallaPush Capacitor SDK

Push notifications for Capacitor apps, built on the SallaPush iOS and Android SDKs.

The TypeScript API calls the native SallaPush SDKs, so an app behaves exactly like a native app on both platforms.

> **Status: in development.** Version 1.0.0 uses SallaPush iOS 1.0.3 and SallaPush Android 1.0.3.
